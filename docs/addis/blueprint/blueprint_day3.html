🛑 HARDWARE E-STOP: 0 ms Instant Power Cut

👷 Human-Centered Safety

  • Human-in-the-Loop Imperative: The AI is a digital apprentice. It advises; the human operator decides and confirms. Zero autonomous moves.
  • Physical Protection: Hard software envelopes prevent moves outside machine stroke (Z-bed floor, B-trunnion limits).
  • Instant Emergency Stop: Red physical mushroom button is hardwired to power relays, completely independent of all AI software.

✅ Graceful Degradation Ladder

  1. Tier 1 · Local AI Assistant: Rich conversational guidance and visual diagnosis running offline on workshop GPU.
  2. Tier 2 · Deterministic Lexicon: If AI hangs or model crashes, keyword lookup provides instant answers (< 1 s).
  3. Tier 3 · Manual CNC Screen: Direct DRO & manual jog controls keep machine producing parts with zero downtime.

👁 Operational Telemetry

  • Local AiTurnJournal: Structured JSONL on disk logs latencies, token usage, tool calls, and safety stops. Zero operator text/audio recorded.
  • Release Fingerprint Gate: CI verifies Model digest + prompt hash + tool schemas before any workshop deployment.
