## Règles de ce dossier

- **Aucun chiffre inventé.** Les valeurs à mesurer sont en `[crochets]`. Les faits renvoient à un fichier, une commande ou une mesure du dépôt.
- Trois étiquettes : **[Note]** (dit par le Concept Note), **[Inférence]** (déduit, à confirmer), **[À vérifier]** (non établi).
- Les documents destinés au programme lui-même (énoncé du défi, registre des risques, dossier d'investissement) seront rédigés **en anglais** ; l'analyse reste en français.
- Le plan se met à jour dans la liste de suivi de `03-plan-adaptation.md` (§12).
