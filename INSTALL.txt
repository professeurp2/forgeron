================================================================================
          GUIDE D'INSTALLATION — FORGERON CNC 5-AXES (WINDOWS)
================================================================================
Distribution Autonome Unifiée - Version 1.0.0 (Hors-Ligne)
Projet Forgeron — Fabrication Numérique et Usinage 5 Axes

Ce paquet d'installation est 100 % autonome : il intègre l'ensemble du système
(interface utilisateur Flutter, moteurs CAO/FAO OpenCASCADE, scan 3D Meshroom,
serveur d'inférence IA Ollama et modèles pré-calibrés).
AUCUNE CONNEXION INTERNET N'EST REQUISE POUR L'INSTALLATION OU L'UTILISATION.

--------------------------------------------------------------------------------
1. CONFIGURATION SYSTÈME REQUISE
--------------------------------------------------------------------------------

- Système d'exploitation : Windows 10 (64-bit) ou Windows 11 (64-bit)
- Processeur (CPU)       : Intel Core i5 / AMD Ryzen 5 (4 cœurs ou supérieur)
- Mémoire vive (RAM)     : 8 Go minimum (16 Go à 32 Go recommandés)
- Carte Graphique (GPU)  : 
  * Recommandé : GPU dédié NVIDIA (RTX 3060, 3070, 4060...) avec 6 à 8 Go VRAM
    pour une inférence IA temps réel ultra-rapide.
  * Compatible : GPU intégré (Intel UHD/Iris Xe) ou processeur multi-cœur via
    le fallback automatique Vulkan / CPU.
- Espace disque libre    : 25 Go minimum (35 Go recommandés sur SSD)
- Réseau                 : Wi-Fi ou câble Ethernet pour dialoguer avec l'ESP32
                           FluidNC de la fraiseuse.

--------------------------------------------------------------------------------
2. FICHIERS DU PAQUET D'INSTALLATION
--------------------------------------------------------------------------------

Le programme d'installation est composé de DEUX fichiers indissociables :

  1. Forgeron_CNC_5Axis_Setup_v1.0.exe (~3,6 Mo)
     -> Le programme d'installation exécutable avec assistant graphique.

  2. Forgeron_CNC_5Axis_Setup_v1.0-1.bin (~14,5 Go)
     -> L'archive de données compressée contenant tout le système.

IMPORTANT :
Ces deux fichiers DOIVENT OBLIGATOIREMENT être placés dans le même dossier
(sur votre disque dur ou votre clé USB). Ne renommez aucun des deux fichiers.

--------------------------------------------------------------------------------
3. ÉTAPES D'INSTALLATION PAS À PAS
--------------------------------------------------------------------------------

Étape 1 : Copie des fichiers
  Placez "Forgeron_CNC_5Axis_Setup_v1.0.exe" et "Forgeron_CNC_5Axis_Setup_v1.0-1.bin"
  dans un même répertoire sur votre PC (ex: Téléchargements ou Bureau).

Étape 2 : Lancement
  Faites un double-clic sur "Forgeron_CNC_5Axis_Setup_v1.0.exe".
  
  * Note SmartScreen Windows :
    Si Windows affiche "Windows a protégé votre ordinateur" :
    1. Cliquez sur le lien "Informations complémentaires".
    2. Cliquez sur le bouton "Exécuter quand même".
    (Avertissement standard sous Windows pour les exécutables industriels
    non signés par un certificat commercial public payant).

Étape 3 : Choix de la langue
  Sélectionnez votre langue d'installation (Français ou Anglais) puis validez.

Étape 4 : Dossier de destination
  L'emplacement par défaut est : C:\Program Files\Forgeron
  Vous pouvez choisir un autre disque si nécessaire (ex: D:\Forgeron).

Étape 5 : Raccourcis
  Laissez cochée l'option "Créer une icône sur le Bureau" pour un accès direct.

Étape 6 : Installation & Carrousel promotionnel
  Cliquez sur "Installer". Pendant la décompression (environ 3 à 5 minutes selon
  votre disque SSD), un carrousel visuel présente automatiquement les atouts
  majeurs de Forgeron (5 axes, IA bilingue Bambara/Français, Jumeau 3D, Sécurité).

Étape 7 : Fin de l'installation
  Cochez "Lancer Forgeron CNC 5-Axes" et cliquez sur "Terminer".

--------------------------------------------------------------------------------
4. FONCTIONNEMENT AUTOMATIQUE DES SERVICES (SANS TERMINAL)
--------------------------------------------------------------------------------

Au démarrage de l'application Forgeron :
- Le superviseur démarre silencieusement en arrière-plan (sans fenêtre noire).
- Le serveur d'IA local Ollama (port 11434) se lance automatiquement et charge
  le modèle de pilotage CNC "forgeron-qwen" et le modèle de vision "gemma3n".
- Le service de scan et reconstruction 3D Reco3D (port 8765) est initialisé.
- Les droits d'accès et redirections nécessaires sous Windows sont gérés de
  manière 100 % transparente.
- Dès que vous fermez Forgeron, tous les services d'arrière-plan sont coupés
  automatiquement pour libérer immédiatement la mémoire vive (RAM) et GPU (VRAM).

--------------------------------------------------------------------------------
5. VÉRIFICATION DU PREMIER LANCEMENT
--------------------------------------------------------------------------------

1. Assistant IA :
   - Rendez-vous dans l'onglet "Assistant IA" de Forgeron.
   - La pastille en haut doit indiquer : "LOCAL · forgeron-qwen:latest".
   - Envoyez un message (ex: "salut"). L'agent répond immédiatement.

2. Connexion Machine :
   - Rendez-vous dans l'onglet "Connexion".
   - Cliquez sur "Scanner" ou saisissez l'adresse IP de l'ESP32 FluidNC.

--------------------------------------------------------------------------------
6. EMPLACEMENT DES JOURNAUX ET DONNÉES
--------------------------------------------------------------------------------

- Dossier du programme    : C:\Program Files\Forgeron\
- Journaux d'activité     : %LOCALAPPDATA%\Forgeron\logs\ (services.log, ollama.log)
- Fichiers temporaires 3D : %LOCALAPPDATA%\Forgeron\reco3d\storage\

--------------------------------------------------------------------------------
7. DÉSINSTALLATION
--------------------------------------------------------------------------------

Pour désinstaller proprement Forgeron :
- Ouvrez "Paramètres Windows" > "Applications" > "Applications installées".
- Recherchez "Forgeron CNC 5-Axes" et cliquez sur "Désinstaller".
- Ou exécutez directement "unins000.exe" dans le dossier d'installation.
